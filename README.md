# 해루 (Heru)

해루는 부모와 아이가 식사·양치·정리·잠자리의 작은 생활 약속을 함께 지키도록 돕는 Android 육아 앱입니다. 도움이 필요할 때는 도깨비 해루와 통화하고, 잘한 순간에는 경고 없이 칭찬하거나 별을 선물할 수 있습니다.

## 주요 기능

- **오늘:** 아이별 활동과 하루 목표 횟수 확인, 진행 중인 활동 이어하기
- **해루 통화:** 상황과 표현 강도를 고르고, 전화 연결·부모 설명·안내·칭찬으로 이어지는 상황극
- **빠른 칭찬과 별:** 통화 없이 칭찬을 선택하거나, 부모가 확인한 활동에 아이가 직접 별 받기
- **보상:** 기본 보상이나 사진으로 목표 설정, 이번 목표의 별과 전체 별 구분, 목표 달성 안내
- **기록:** 자녀별 날짜 기록과 최근 7일의 활동 요약
- **중간 저장:** 앱을 닫거나 다른 앱을 사용한 뒤에도 홈에서 활동 이어하기
- **선택적 전면카메라:** 통화 화면에 아이 모습 미리보기. 카메라 영상은 저장하거나 전송하지 않습니다.

식사 대사는 직접 녹음한 음성을 사용합니다. 양치·정리·잠자리는 음성 추가 전에도 대사와 캐릭터 화면으로 전체 흐름을 확인할 수 있습니다. 기록과 보상 사진은 현재 기기에 보관됩니다.

## 기술 스택과 선택 이유

| 기술 | 선택 이유 |
| --- | --- |
| Kotlin · Android 네이티브 | 익숙한 환경에서 기기 기능과 사용자 흐름을 빠르게 개발하기 위해 |
| Jetpack Compose · Material 3 | 부모용 관리 화면과 아이용 캐릭터 화면을 일관되게 구성하기 위해 |
| ViewModel · 코루틴 | 화면 상태와 재생을 관리하고 저장 작업을 화면 밖에서 처리하기 위해 |
| Room · SQLite | 자녀·활동·기록·별·보상 목표를 연결하고 완료와 별 지급을 함께 저장하기 위해 |
| MediaPlayer · WAV | 녹음된 대사를 네트워크 없이 재생하기 위해 |
| CameraX | 선택적 전면카메라 미리보기를 제공하고 화면을 벗어나면 해제하기 위해 |
| Photo Picker · ExifInterface | 선택한 보상 사진을 작고 올바른 방향으로 기기에 보관하기 위해 |
| JUnit · Robolectric | 에뮬레이터 없이 계산, 데이터 이관과 저장의 일관성을 검증하기 위해 |
