# 해루 (Heru)

해루는 부모가 고른 말을 도깨비 캐릭터가 아이에게 들려주는 Android 육아 앱 시제품입니다. 식사 시간이 되면 부모가 상황에 맞는 안내를 선택하고, 아이가 식탁에 온 뒤에는 칭찬을 들려줄 수 있습니다.

## 주요 기능

- 식사 안내 대사 5단계를 선택해 미리 듣고, 칭찬 대사 5단계는 화면의 문구를 보고 별도로 선택
- 전화 신호음이 흐르는 발신 화면에서 부모가 연결하면 해루의 인사, 부모의 상황 설명, 선택한 경고 음성이 차례로 진행
- 인사 녹음이 준비되기 전에는 기기 음성으로 "여보세요"를 임시 재생
- 부모가 선택하면 통화 중 전면카메라로 아이 모습을 작은 창에 표시하기(저장·전송 없음)
- 같은 안내 다시 들려주기, 식사 종료 대사 재생
- 아이가 화면의 별을 직접 눌러 보상을 받고 별의 진행 상황 확인
- 선택값, 별 개수, 최근 사용 기록을 기기에 저장

## 기술 스택과 선택 이유

| 기술 | 선택 이유 |
| --- | --- |
| Kotlin · Android 네이티브 | 현재 가장 익숙한 개발 환경에서 Android 시제품을 빠르게 만들고 검증하기 위해 |
| Jetpack Compose · Material 3 | 부모용 선택 화면과 아이용 캐릭터 화면을 코드로 빠르게 만들고 수정하기 위해 |
| ViewModel · Kotlin 코루틴 | 화면 상태와 3초 준비 시간을 안정적으로 관리하기 위해 |
| Android MediaPlayer · WAV | 직접 녹음한 대사를 네트워크 연결 없이 바로 재생하기 위해 |
| CameraX | 전면카메라 미리보기를 통화 화면에 띄우고 화면을 벗어나면 해제하기 위해 |
| SharedPreferences | 초기 시제품의 선택값과 별·기록을 기기에 간단히 저장하기 위해 |
