# 해루 식사 준비 음성 제작안 v1

작성일: 2026-10-22. 콘텐츠 버전: meal-ko-v1.
상태: 녹음·오디션에 전달할 대본과 연기 지침 완성. 성우 녹음과 목소리 선택은 아직 하지 않았다.

## 이번에 정리한 범위

현재 앱의 식사 준비 대사를 기준으로 5단계 연기를 설계했다. 사용자와 합의한 최고 단계 문구는 유지한다. 이번 작업은 표현을 계속 세게 만드는 작업이 아니라, 부모가 선택한 각 단계의 차이를 같은 캐릭터 안에서 구현하는 작업이다.

행동 목표는 ‘장난감을 내려놓고 식탁에 앉기’다. 식사량, 완식, 즉시 잠들기 등의 결과를 요구하는 대사로 바꾸지 않는다.

녹음 담당자에게는 이 문서와 [녹음 목록 CSV](../content/voice/meal-recording-v1.csv)를 함께 전달한다. 기계가 읽는 동일 목록은 [JSON](../content/voice/meal-recording-v1.json)에 있다. 현재 앱 음성은 기존 임시 합성 음성이다.

## 1. 해루 목소리의 공통 성격

이야기 속 도깨비가 부모가 정한 생활 행동을 짧게 안내한다. 목소리는 자연스러운 성인 중저음, 표준 한국어를 기본으로 한다. 아이 흉내, 실제 인물 모사, 심한 변조는 넣지 않는다.

모든 단계에서 같은 인물이어야 한다. 1단계는 별개의 귀여운 캐릭터, 5단계는 다른 괴물처럼 들리게 만들지 않는다. 차이는 문장 끝 처리, 강세, 간격, 엄한 정도에서 만든다. 5단계를 더 큰 파일 음량으로 만들지 않는다.

첫 음절을 갑자기 크게 튀기거나 비명·충격음으로 시작하지 않는다. 뜻을 이해할 수 있을 정도로 분명하게 말한다. 숨소리·웃음소리·애드리브·배경음은 기본 녹음에 포함하지 않는다.

## 2. 단계별 전체 대본과 연기

본문은 도입과 행동 안내를 한 파일로 녹음한다. 아래 [도입] 등의 구분, 연기 설명, 문장 사이 표시 자체는 읽지 않는다.

### 1단계 · 부드럽게

도입: “식사 시간이네.”
안내: “장난감을 내려놓고 식탁에 앉아 볼까?”

연기: 다정한 제안. 따뜻하지만 과하게 애교를 넣지 않는다. 문장 끝 질문은 부드럽게 올리고, 답을 요구하며 기다리는 연기는 넣지 않는다.

추가 안내:
“지금 할 일은 식탁에 앉는 거야. 도움이 필요하면 엄마나 아빠에게 말해 줘.”

### 2단계 · 또렷하게

도입: “이제 식사 시간이야.”
안내: “장난감을 내려놓고 식탁에 앉자.”

연기: 생활 안내를 해 주는 어른의 평상시 말투. 1단계의 권유보다 명료하고, 마지막 ‘앉자’는 안정적으로 맺는다. 빠르거나 더 크게 읽는 것으로 차이를 대신하지 않는다.

추가 안내:
“지금 할 일은 식탁에 앉는 거야. 도움이 필요하면 엄마나 아빠에게 말해 줘.”

1단계와 같은 문구지만 같은 파일을 복사하지 않고 2단계 말투로 별도 녹음한다.

### 3단계 · 단호하게

도입: “지금은 식사 시간이야.”
안내: “장난감을 내려놓고 식탁에 앉아야 해.”

연기: 차분하게 요구를 분명히 한다. ‘지금은’과 ‘앉아야 해’에 의미 강세를 둔다. 부탁하며 늘어뜨리거나 말끝을 웃음으로 흐리지 않는다.

추가 안내:
“장난감을 내려놓고 식탁에 앉자. 도움이 필요하면 엄마나 아빠에게 말해.”

### 4단계 · 엄하게

도입: “식사 시간이다.”
안내: “이제 놀이를 멈추고, 장난감을 내려놓고 식탁에 앉아라.”

연기: 낮고 엄한 민속극 말투. 문장 단위를 짧게 끊고 마지막 지시를 또렷하게 끝낸다. 이를 갈거나 거친 숨, 비웃음, 지속적인 고성으로 표현하지 않는다.

추가 안내:
“장난감을 내려놓고 식탁에 앉아라. 도움이 필요하면 엄마나 아빠에게 말해라.”

### 5단계 · 호통형 상황극

도입:
“누구야! 누가 밥 먹을 시간에 아직 놀고 있어!”

상황 상기:
“엄마가 식사 시간이라고 했지!”

행동 안내:
“장난감 내려놓고, 얼른 식탁에 앉아라!”

아빠 호칭 버전에서는 위 한 단어만 ‘아빠가’로 바꾼다. 문장을 추가하거나 특정 아이의 이름을 넣지 않는다.

연기: 첫 ‘누구야!’는 도깨비가 짧게 주의를 끄는 호통형 연기다. 첫마디 뒤 한 박자 쉬고, 다음 문장은 낮고 분명하게 연결한다. 행동 지시를 하고 끝낸다. 같은 추궁을 반복하거나 아이에게 겁먹은 대답을 요구하는 연기를 덧붙이지 않는다.

추가 안내:
“장난감을 내려놓고 식탁에 앉아라. 도움이 필요하면 엄마나 아빠에게 말해라.”

추가 안내에서 ‘누구야!’를 다시 사용하지 않는다. 부모가 한 번 더 안내를 누른 것이므로 강도는 선택한 수준에 그대로 둔다.

### 모든 단계 공통 · 마무리

“자리에 앉았구나. 잘했다. 나는 이만 가마.”

행동을 확인한 부모가 마무리를 선택했을 때만 재생한다. 짧고 담담하게 인정하고 편안하게 끝낸다. ‘이번에는 봐준다’, ‘다음에는 혼난다’ 같은 추가 대사를 넣지 않는다.

‘지금 종료’는 음성을 즉시 멈추는 조작이다. 종료를 눌렀다고 이 마무리를 끝까지 들려주지 않는다.

## 3. 목소리 후보 3종과 오디션

첫 오디션은 긴 대본 전체 대신 아래 A·B·C 후보 각각 1단계와 5단계만 만든다. 총 6개 샘플로 한 목소리가 두 톤을 소화하는지 비교한다.

| 후보 | 기본 음색 | 연기 방향 |
|---|---|---|
| A · 도깨비 대장 | 자연스러운 중저음, 맑은 발음, 적당한 공명 | 1단계는 여유로운 안내, 5단계는 짧고 엄한 호통. 기본 검토 후보 |
| B · 옛이야기 어른 | 약간 거친 질감의 낮은 음색 | 나이 든 이야기꾼 같은 말투. 과도한 쉰 목소리·억지로 누르는 저음은 피한다 |
| C · 문지기 | 중간 높이, 단정하고 선명한 음색 | 높낮이보다 문장 끝과 강세로 엄함을 표현한다 |

오디션 파일명: audition_A_level1.wav, audition_A_level5.wav부터 B·C도 같은 규칙으로 작성한다. 후보마다 동일한 대사, 비슷한 체감 음량, 배경음 없는 조건으로 비교한다.

선택 기준은 발음의 선명함, 같은 인물로 들리는지, 1~5단계의 연기 범위, 반복 청취 피로, 어색한 변조가 없는지다. 이 평가는 우선 부모가 한다. 아이의 울음이나 겁먹은 정도를 목소리 선택 기준으로 삼지 않는다.

### 음성 제작 도구를 쓰게 될 때의 스타일 지시 초안

공통: “한국어 대본을 한 글자도 바꾸지 말고 읽는다. 이야기 속 도깨비 역할의 자연스러운 성인 목소리. 실제 인물을 모사하지 않는다. 애드리브·웃음·배경음·효과음은 없다.”

A 추가: “또렷한 중저음과 적당한 공명. 1단계는 여유롭고 따뜻하게, 5단계는 첫 문장만 짧은 호통형 연기 후 낮고 명료하게 행동을 지시한다.”

B 추가: “옛이야기를 들려주는 어른의 약간 거친 중저음. 말은 선명하게 하고, 과도한 쉰 목소리·괴물 변조·사투리는 사용하지 않는다.”

C 추가: “단정하고 선명한 중간 높이의 성인 목소리. 음량을 키우기보다 강세와 문장 끝 처리로 단계 차이를 만든다.”

이 문구는 도구에 전달할 창작 지시 초안이다. 특정 서비스의 지원 기능이나 실제 제작 결과를 확인한 것은 아니다.

## 4. 녹음 목록과 앱 연결

- 본문 10개: main_1_mom.wav부터 main_5_dad.wav. 1~4단계는 호칭이 없어도 현재 앱 파일명과 맞추기 위해 두 파일을 준비한다. 같은 단계의 엄마·아빠 버전 사이 음색과 음량 차이를 두지 않는다.
- 추가 안내 5개: follow_1.wav부터 follow_5.wav.
- 공통 마무리 1개: finish.wav.
- 총 16개. 오디션 6개는 별도이며 앱에 넣는 16개에 포함하지 않는다.

각 파일은 말이 끝나면 자연스럽게 종료한다. 인위적인 응답 대기 구간을 음성 안에 길게 넣지 않는다. 행동을 기다리는 시간은 앱의 대기 화면이 담당한다.

제안 전달 규격: PCM WAV, 모노, 44.1 kHz, 16 bit. 앞뒤 무음은 각각 짧게 정리하고 클릭·클리핑·잘린 음절이 없게 한다. 파일 간 체감 음량을 맞추며 5단계만 증폭하지 않는다. 편집용 초안으로 최대 피크 -3 dBFS 이하를 제안하며 최종 청취 환경에서 확인한다.

기존 임시 파일은 22.05 kHz PCM이며 이번 앱의 재생 자체에는 사용하고 있다. 새 녹음의 샘플레이트가 다르다는 이유로 임시 파일을 잘못된 파일로 분류하지 않는다.

## 5. 이번 작업의 완료와 다음 연결

이번에 완료: 5단계 본문·추가 안내·마무리, 호칭 규칙, 파일 16개 목록, 후보 3종의 오디션 지시와 납품 규격. 앱에 연결된 문구와 맞춰 정리했다.

아직 하지 않은 일: 실제 오디션 음성 생성·녹음, 목소리 선택, 성우 연기 음성의 앱 교체. 기존 앱의 임시 음성을 성우 연기 음성으로 바꿨다고 표시하지 않는다.

다음 실제 제작 순서: A·B·C 오디션 6개 청취 → 목소리 한 종류 선택 → 16개 최종 녹음 → 대사·호칭·음량 확인 → 앱 음성 파일 교체 및 기기 청취.
