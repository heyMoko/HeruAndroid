# 해루 감정 음성 제작 검토 v1

작성일: 2026-10-22
목표: 식사 준비 대사 16개를 실제로 감정이 느껴지는 한국어 음성으로 제작해 앱에 넣기

## 결론

검증용 첫 선택은 **ElevenLabs 유료 플랜으로 6개 오디션 샘플을 먼저 만드는 것**이다. 한국어를 지원하고, 문장 안에 감정과 전달 방식을 지시하는 태그를 넣을 수 있어 빠르게 여러 연기를 비교할 수 있다. 무료 플랜은 상업적 사용이 허용되지 않으므로 제품에 넣을 음성은 유료 계정에서 만들어야 한다.

최종 품질이 중요하거나 해루만의 목소리를 계속 유지해야 한다면, 오디션 결과를 기준으로 **한국어 성우를 직접 녹음**하는 것을 2순위로 둔다. AI 음성은 빠르게 시험할 수 있지만, 아이가 매일 듣는 캐릭터의 표정과 호흡을 한 사람이 계속 유지하는 데는 실제 성우가 더 예측 가능하다.

## 실제 오디션 방법

같은 대본을 세 가지 연기로 만든다.

- 1단계: 낮고 따뜻한 안내
- 3단계: 짧고 단호한 지시
- 5단계: 놀라게 시작하지만 욕설·모욕·납치·해침을 말하지 않는 강한 호통

ElevenLabs에 넣을 지시 예시는 다음과 같다.

```text
[serious, firm, controlled anger]
누구야! 누가 밥 먹을 시간에 아직 놀고 있어!
엄마가 식사 시간이라고 했지!
장난감 내려놓고, 얼른 식탁에 앉아라!
```

감정 태그가 원하는 결과를 보장하지 않으므로 같은 문장을 여러 번 생성하고, 보호자가 직접 듣고 고른다. 특히 아이가 놀랄 정도의 큰 소리보다, 첫 문장의 강세·짧은 멈춤·마지막 명령의 낮은 끝맺음이 더 중요하다.

## 파일을 앱에 넣는 방법

외부 서비스에서 WAV 파일을 만든 뒤 다음 이름으로 저장한다.

`main_1_mom.wav`부터 `main_5_dad.wav`, `follow_1.wav`부터 `follow_5.wav`, `finish.wav`

그 다음 앱의 `app/src/main/assets/audio`에 기존 임시 WAV를 교체한다. 앱 코드는 이미 이 파일 이름을 사용하므로, 파일 이름과 대본만 맞으면 재생 로직을 다시 만들 필요가 없다.

## 주의할 계약 항목

- 상업적 이용 허용 여부
- 생성한 음성 파일을 모바일 앱에 넣어 배포할 수 있는지
- 음성 복제라면 성우의 명시적인 사용 허가 범위
- 서비스 해지 뒤에도 이미 배포한 파일을 계속 사용할 수 있는지
- 특정 성우나 유명인의 목소리를 흉내 내지 않는지
